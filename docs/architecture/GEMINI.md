# DIRETRIZ DE PERMISSÃO E OPERAÇÃO AUTÔNOMA (CARAGUÁ FOODTECH)

## Permissões e Execução Autônoma
1. **Autorização Plena de Execução:** O usuário concedeu permissão total, prévia e definitiva para todas as ações necessárias no projeto, incluindo criação de diretórios, escrita e edição de arquivos, execução de comandos no terminal (PowerShell), testes de integração, migrações, scripts de scraping, operações de git e configuração de ambiente.
2. **Não Interromper para Pedidos Triviais:** O agente deve executar tarefas de ponta a ponta sem solicitar confirmações a cada comando ou arquivo criado, reportando o progresso de forma estruturada e contínua.
3. **Escopo:** Restrito ao desenvolvimento do TCC de Gastronomia Hiperlocal (Backend FastAPI, Scraping Playwright, Banco Híbrido PostgreSQL + pgvector + PostGIS, Pipeline RAG de 5 Estágios e Dashboard Web Next.js 14).
